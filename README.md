# Llenguatge musical Rockin

Web per practicar llenguatge musical aplicat als instruments de Rockin, amb el navegador i sense instrument.

Cada tema comença amb una base que sona i mostra al pal o al teclat com es toca. Després es treballen els ingredients pas a pas (lliçons curtes amb un repte petit), es practiquen amb reptes i el tema s'acaba tocant amb la banda.

- **Guitarra:** riff de power chords, balada amb arpegis, i entrenament de distàncies al pal (octava, 5a, 4a, 3es) i contrarellotge.
- **Baix:** línia de rock (fonamental, 5a i octava), línia amb 3es i reptes de velocitat al pal.
- **Teclat:** construir acords comptant semitons; el primer tema és la progressió pop Do – Sol – La m – Fa.
- **Bateria:** cops simples, dobles i paradiddles, tocats a temps amb les tecles F (mà esquerra) i J (mà dreta) o amb la pantalla tàctil, i un generador lliure de paradiddles.
- **Dictat rítmic:** sona una carta de patrons rítmics de Rockin i cal triar quina és.

El progrés es desa al navegador de cada dispositiu. Al mode professorat totes les etapes són obertes.

## Fitxers

- `index.html`: tota l'aplicació (HTML, CSS i JavaScript, sense dependències ni compilació).
- `cartes/`: imatges de les cartes de patrons rítmics.
- `marca/`: logotip i icona de Rockin.

Per provar-la en local: `python3 -m http.server` dins la carpeta i obrir `http://localhost:8000`.
